# House of Press

Hand-set, hand-pressed letterpress business cards, made in Bombay.

**Live: https://jami-and-corp.github.io/houseofpress/**

This repository holds only the published site — the five pages, one stylesheet,
one script, and the images the pages load. It exists so GitHub Pages has
something public to serve.

The working project — source artwork, the studio's own material, and the tools
that build the assets — lives in a separate private repository and is not
mirrored here.

Static. No build step, no CDN: everything is served straight from this folder.
